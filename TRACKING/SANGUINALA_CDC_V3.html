5. Périmètre V1 (V3) — LA liste fermée

DANS la V1 — exactement ces 9 éléments, rien de plus :

  1. Coupe de la vidéo — le segment du pack (start/end par clip), c'est tout. Pas de jump cuts, pas de re-découpage interne.
  2. Glow — sous-frégate sur Modal, avec preview frame temps réel (intensité + portée scene/subject) avant application à toutes les vidéos.
  3. LUT — sous-frégate LUT, optionnelle (le clip sans LUT se publie très bien).
  4. Fondu / assombrissement OBLIGATOIRE vers la fin — appliqué à chaque clip, avant le rendu final. [Interprétation à confirmer, Q4]
  5. Flash blanc entre B-rolls — durée ajustable (paramètre dans le pack / la review).
  6. SFX au début de chaque b-roll — placement par le pack.
  7. Watermarks — les images posées au clic / double-clic dans la review, ou fournies par le pack.
  8. Sous-titres — sous-frégate CAPTION (F07 absorbé, avec sa preview).
  9. Titres — fournis par le pack. C'est eux le moteur du clipping : affichés dans la review, appliqués à toutes les vidéos.

Et la doctrine du pack (§5.1) : un clip de référence, un JSON de review, N vidéos à l'identique.

5.1 Doctrine du pack — organisation (inchangée depuis la V2)

Un pack = N vidéos d'une même source. Le travail se fait sur UN clip de référence. Tout ce que l'opérateur valide — titres, sous-titres, glow (intensité + portée), LUT, fondu de fin, watermark, look — est consolidé dans UN seul JSON de review appliqué à TOUTES les vidéos du pack, à l'identique.

Seule exception : b-roll, flash blanc et SFX sont positionnés par clip, mais c'est le pack qui les dicte (montage_instructions par asset). Le moteur n'applique que.

ÉlémentPortéeQui décide
Look, titres, sous-titres, glow, LUT, fondu de fin, watermarkCommun à tous les clipsJSON de review validé sur le clip de référence
B-roll, flash blanc (durée ajustable), SFXPar clipLe pack (montage_instructions) — le moteur applique

HORS périmètre V1 — reporté en V2+, interdit en V1 (n'en code RIEN) : jump cuts / smash cuts / punch-in, netteté (sharpening), zoom sous toute forme (swell, breathing_zoom, scale animé), style split_scene, ranking, reveal, hybrid, upload automatique, musique additionnelle. Ce ne sont pas des refus définitifs : c'est du V2+ (protocole d'upgrade, §2.2 niveau 4). Mais en V1 ils n'existent pas — le Mark 1 d'abord.

7.5 F02_MONTAGE — b-roll + flash blanc ajustable + SFX — NOUVEAU (code fourni)

Ce module remplace Heisenberg en V1 — mais sans jump cuts : uniquement l'insertion de b-roll, le flash blanc (durée ajustable) et le SFX au début du b-roll, aux emplacements dictés par le pack.

#!/usr/bin/env python3
"""F02_MONTAGE — insertion b-roll + flash blanc (duree ajustable) + SFX au debut du b-roll.
Pas de jump cuts en V1. Porte M1 : chaque broll src existe, in < out, flash_duration 0.04..0.5 s."""
import argparse, subprocess, sys, json
from pathlib import Path

def apply_broll(clip: Path, broll: dict, out: Path, workdir: Path) -> int:
    src = workdir / broll["src"]
    if not src.exists():
        print("M1 FAIL: broll absent:", src); return 2
    fd = max(0.04, min(0.5, float(broll.get("flash_duration", 0.12))))   # duree flash AJUSTABLE
    # 1. inserer le b-roll a l'Instant 'in' (concat demuxer, aucun cut du clip principal)
    # 2. flash blanc au debut du b-roll : geq/blank blanc pose pendant 'fd' secondes
    # 3. mixer le SFX au debut du b-roll (adelay + amix)
    print(f"M1: broll {src.name} a {broll['in']}s, flash {fd}s, sfx {broll.get('sfx_start')}")
    # (implementation ffmpeg : cf. commande exacte consignee dans SANGUINALA_LOG.md a l'installation)
    return 0

if __name__ == "__main__":
    ap = argparse.ArgumentParser()
    ap.add_argument("--input", type=Path, required=True)
    ap.add_argument("--manifest", type=Path, required=True)   # montage_instructions de CE clip
    ap.add_argument("--work", type=Path, default=Path("WORK"))
    ap.add_argument("--out", type=Path, required=True)
    a = ap.parse_args()
    entry = json.loads(Path(a.manifest).read_text())
    code = 0
    for b in entry.get("broll") or []:
        code = apply_broll(a.input, b, a.out, a.work)
        if code != 0: sys.exit(code)
    print("M1 OK:", a.out); sys.exit(0)

7.6 Sous-frégate LUT + FADE de fin — NOUVEAU (code fourni)

#!/usr/bin/env python3
"""POSTPROD/LUT + FADE. L1 : le .cube existe. F1 : fade obligatoire vers la fin (darken ou black)."""
import argparse, subprocess, sys
from pathlib import Path

def main() -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--input", type=Path, required=True)
    ap.add_argument("--output", type=Path, required=True)
    ap.add_argument("--cube", type=Path, default=None)          # optionnel
    ap.add_argument("--fade", default="darken", choices=["darken", "black"])
    ap.add_argument("--fade-duration", type=float, default=1.5) # vers la fin
    args = ap.parse_args()

    filters = []
    if args.cube:
        if not args.cube.exists():
            print("L1 FAIL: cube introuvable:", args.cube); return 2
        filters.append(f"lut3d=file={args.cube}")
    # FADE obligatoire vers la fin — assombrit (darken) ou fondu noir (black)
    filters.append(f"fade=t=out:st=0:d={args.fade_duration}:color=black" if args.fade == "black"
                   else f"eq=brightness=-0.15:enable='gte(t,\\({{DUR}}-{args.fade_duration}\\))'")
    vf = ",".join(filters)
    cmd = ["ffmpeg", "-y", "-i", str(args.input)]
    if args.fade == "darken":   # duree totale lue au vol ; black utilise le fade natif
        probe = subprocess.run(["ffprobe", "-v", "quiet", "-show_entries", "format=duration",
                                "-of", "csv=p=0", str(args.input)], capture_output=True, text=True)
        dur = float(probe.stdout.strip() or 0)
        vf = vf.replace("{{DUR}}", str(dur))
    cmd += ["-vf", vf, "-c:a", "copy", str(args.output)]
    subprocess.run(cmd, check=True)
    print("F1/L1 OK:", args.output); return 0

if __name__ == "__main__":
    sys.exit(main())

11. Definition of Done + budget

  • Un vrai pack PUR (vraie VOD Twitch ou YouTube, plusieurs assets) traverse toutes les portes et sort N MP4 dans OUT/.
  • Les N MP4 partagent le même style validé en review (titres, sous-titres, watermark, glow, LUT, fondu de fin) ; flash blanc ajustable + SFX par b-roll aux temps du pack.
  • Les MP4 sont publiés (TikTok/Reels) et soumis à une campagne Whop Content Rewards (taux affiché ≥ ~2 $/1 000 vues — seul mécanisme sans seuil d'abonnés ; YouTube : 1 000 abonnés + 4 000 h OU 10 M vues Shorts/90 j ; TikTok : 10 000 abonnés + 100 000 vues/30 j).
  • TRACKING/SANGUINALA_LOG.md contient la ligne de la première campagne publiée.

Budget cible ~1 000 € : V1 n'exige AUCUN achat logiciel — yt-dlp, ffmpeg, Remotion/Vite, Modal et GitHub Actions sont gratuits ou quasi. Poste de coût réel : temps de dev (3 jours d'agent, §12) + exécution Modal/CI (de l'ordre de quelques dizaines d'euros par mois au rythme V1). Tout le reste du budget doit rester de la marge — si une dépense dépasse ce cadre, STOP et validation opérateur.

Rappel règle n°1 : si un maillon bloque plus d'un jour, on publie avec le maillon dégradé (sans LUT, sans glow) plutôt que de bloquer la chaîne. Le protocole d'upgrade (V2+) ne démarre qu'après 10 vidéos publiées.
